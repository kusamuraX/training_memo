# 筋トレ記録アプリ
used (riverpod + go_router + drift)

## アプリ概要
効率的なトレーニング管理と詳細な分析機能を備えた包括的な筋トレ記録アプリケーションです。
リアルタイムの統計情報、視覚的なデータ分析、履歴管理を通じて、トレーニングの継続と向上をサポートします。

## 技術スタック
- **フレームワーク**: Flutter
- **状態管理**: Riverpod
- **ナビゲーション**: Go Router
- **データベース**: Drift（SQLite）
- **対応プラットフォーム**: iOS、Android、Web、Windows、macOS、Linux

## 主要機能

### 1. メイン画面（トレーニング部位選択）
- **6つの部位選択**: 胸、背中、肩、腕、腹、脚から選択してトレーニング開始
- **今週の総負荷重量**: 先週比との増減率を表示
- **本日の部位別総負荷重量**: 各部位の当日実績をグリッド表示
- **5週間推移グラフ**: 部位別負荷重量の視覚的トレンド分析
- **リアルタイム統計**: トレーニング状況の即座把握

### 2. 履歴画面（トレーニング履歴）
- **カレンダー形式表示**: 月表示で日本語ロケール対応
- **トレーニング日マーカー**: 実施部位を色分けした視覚的マーカー
- **詳細履歴表示**: 重量、回数、RM値の一覧表示
- **履歴編集機能**: ダブルタップで過去データの編集
- **新規追加**: 任意の日付への追加トレーニング入力

### 3. 設定画面
- **トレーニング編集**:
  - 部位別種目の追加・削除
  - カスタムメニューの作成
- **データ引継ぎ**:
  - JSON形式でのエクスポート・インポート
  - ローカル保存・クラウド共有対応
  - Googleドライブ、Dropbox等への保存

### 4. トレーニング実行画面
- **前回データ参照**: 前回実績の表示で効率的な入力
- **リアルタイム計算**: 総負荷重量の即座計算
- **セット管理**: 重量、回数、RM値、メモの管理
- **自動保存**: データの即座保存機能

### 5. データ分析機能
- **総負荷重量計算**: 重量×回数の自動計算
- **週次比較分析**: 前週との詳細比較
- **部位別統計**: 各部位の負荷分布分析
- **視覚化**: グラフとチャートによるデータ可視化

## データ構造

### データベーステーブル
1. **BodyPartsInfo（部位マスタ）**: 部位ID、部位名
2. **PartsTrainingInfo（トレーニング種目）**: 部位ID、種目ID、種目名
3. **TrainingDataInfo（トレーニング実績）**: 部位ID、種目ID、実施日、重量、回数、RM値、メモ

### 初期データ
- **6つの部位**: 胸、背中、肩、腕、腹、脚
- **50種類以上の基本種目**: 各部位に対応した豊富なトレーニングメニュー

## 特徴

### パフォーマンス
- **高速データアクセス**: SQLiteによるローカルデータベース
- **効率的状態管理**: Riverpodによるキャッシュと最適化
- **レスポンシブUI**: 全プラットフォーム対応の統一UI

### ユーザビリティ
- **直感的操作**: シンプルで分かりやすいインターフェース
- **カラーコーディング**: 部位別の色分けによる視認性向上
- **データ継続性**: 安全なデータ移行とバックアップ機能
